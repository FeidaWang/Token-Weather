MIT open-source 1.0.0. Maintained by Feida Wang, trading as RSI AI.

Read available local Codex metrics, plan room for your next task, and deploy numeric planning on your own server. The publisher operates no shared budget MCP and no paid model API is called by this software.

Download 1.0.0 | Source code | Release notes

What it can do today

  • The local-only MCP reads the exact requested Codex root's compatible numeric events and updates reference budget, task-size and output-reserve advice.
  • The remote/self-hosted tool calculates budgets from explicit numeric inputs. It cannot read your private ChatGPT context, account quota or local Codex files.
  • The existing local weather page and checkpoints remain available; normal hook review is retained.
  • Model changes, effort changes and automatic chat rotation are disabled until a supported exact-owner control path and policy are verified.

A watch command can refresh local observations and advice. This does not make exact active context measurable or turn recommendations into executed controls. Missing data stays unknown.

Your deployment, your control

Run locally without a new subscription, or self-host on a server you choose. You control its access, provider logs, retention and costs. No public MCP was deployed by the publisher and source publication is not plugin-directory approval.

The native Python backend passed an actual temporary loopback TLS-proxy test. Docker/Caddy, public DNS and existing Desktop controls are not claimed as verified.
