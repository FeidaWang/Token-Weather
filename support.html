Token Weather Support

Maintained by Feida Wang, trading as RSI AI as a sole trader.

For general questions or bug reports, use GitHub Issues. Search existing issues before opening a new one. A GitHub account is needed to participate.

Include the Token Weather version, operating system, Codex version, what you expected and what happened. A short sanitised error message or redacted screenshot can help.

Issues and comments are public. Do not post chat transcripts, private project files, unredacted logs, passwords, API keys, identity documents or local service control tokens. Token Weather does not offer email support. Support is maintained on a best-effort basis, with no fixed response time.

For local data removal, stop the relevant weather service or workflow writers before removing the separate Token Weather cache or workflow directory. Archiving a Codex chat does not remove these files. Ask a general question in Issues if you need help with these steps, without posting private data.

Public support history has no 30-day automatic expiry. Closing an issue does not delete it. Use GitHub's controls where available or identify the relevant issue/comment in a minimal removal request; do not add sensitive material to the request.

Read the privacy policy for data handling and user controls.
