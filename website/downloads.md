- [Get the source as a GitHub archive](https://github.com/FeidaWang/Token-Weather/archive/refs/tags/v1.0.0.zip)

Use Python 3.9+ for numeric planning and Python 3.11+ for local Codex inspection. Optional Docker/Caddy deployment requires your own chosen server, DNS and image downloads. These may have deployer-selected costs.

The earlier skills-only candidate is a separate local historical artifact. It is not silently overwritten or presented as the new open-source download. No account registration or publisher-hosted budget service is required for local use.
