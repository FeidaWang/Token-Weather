# Start here

This is the MIT open-source Token Weather 1.0.0 edition. GitHub source publication does not establish directory approval or a publisher-hosted MCP.

## Budget planning

1. Open the local demo using the README command, or use a host where the real budget MCP is already connected.
2. Supply a reference limit and compatible usage estimate. Missing numbers stay unknown; partial results are useful.
3. For a next-task scenario, supply the increase and a separate output reserve. Zero is used only when intended.
4. For an outlook, supply three to six chronological turn totals; the last matches usage. An observed decrease resets the growth sample.
5. Read current headroom, planned headroom and overage separately. The linear forecast cannot promise actual compaction timing.

Weather ranges are Clear below 35%, Fair from 35% to below 55%, Cloudy from 55% to below 70%, Showers from 70% to below 85%, and Storm at or above 85% of the supplied reference. Fractions above 100% are reported as over-budget.

The tool does not inspect private ChatGPT context, account quota or message text. Platform names alone establish neither current usage nor a reference limit. Never send transcripts or credentials.

## Local Codex readings

Use the existing weather skill only for a requested compatible local Codex reading. It locates the exact chat record and checks the chat/project match. That access is separate from numeric planning. See LOCAL-SETUP.md.

The existing single-page weather display is unchanged. Its collection service can continue after the browser tab closes; stop it explicitly for that chat. Checkpoints require already enrolled workflows. Automatic chat moving stays disabled.

For help see SUPPORT.md. A missing reading is not zero usage; do not post private records in public Issues.

For automatic local metrics, use inspect_local_context or the local-observe watch command in README.md. Both use the exact root/workspace and update advice only. Automatic model, effort and chat controls are disabled; see AUTOMATION.md.
