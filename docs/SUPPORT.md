# Token Weather support

Maintained by Feida Wang, trading as RSI AI. General help and bug reports use
public [GitHub Issues](https://github.com/FeidaWang/Token-Weather/issues).
Email support is not offered.

For a budget problem, give synthetic numbers, expected arithmetic, version and
observed result. Distinguish supplied usage from assumed task estimates. Do
not send a full chat, API key or personal usage history.

For a local reading problem, include version, operating system and a short
redacted description. Do not attach JSONL records, private project files,
unredacted logs, paths, chat IDs, credentials or identity documents.

## Common questions

- With no reference limit, planned usage can be calculated; headroom, weather
  and fit stay unknown.
- Recent totals must be compatible; the last matches supplied usage. Do not
  change conflicting observations just to pass validation.
- The MCP cannot obtain private current ChatGPT context or account quota.
- ChatGPT web cannot connect to this local stdio/loopback preparation. Public
  remote setup is incomplete.
- Old skills scan passes apply to the previous draft; new skills need new scans.
- Stop the demo using Ctrl+C. The original local weather service has its own
  explicit stop command and may continue after its tab closes.

Issues are public support history. Use GitHub controls where available for your
issue/comment. Do not disclose sensitive data to request help or deletion.
