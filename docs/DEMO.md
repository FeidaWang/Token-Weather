# Local rehearsal and review recording

The included browser demo makes real MCP calls with synthetic numeric inputs.
It is a local rehearsal, not the required intended-host review video.

Start `python3 -B mcp/demo/server.py --port 0` from the package root, then open
the printed URL. Initialization, discovery and calculations are real. No paid
model API or hosting is needed.

1. **Next task:** show 100000 limit, 65000 used, 20000 increase and 5000 reserve;
   read 35000 current headroom and 10000 planned headroom.
2. **Five-turn outlook:** show compatible totals and all five projections.
   Explain the assumption and unknown real compaction policy.
3. **Over budget:** show zero remaining and planned overage 25000.
4. **Unknown limit:** show Unknown headroom while planned usage remains 90000.
5. **Rejected private fields:** use synthetic markers only; display the actual
   rejection. No real transcript or API key is used.
6. Expand Actual MCP request and response to inspect the tool call.

Stop the demo with Ctrl+C. The original weather page uses another service and
its own stop command. This does not install a plugin in ChatGPT or Codex.

For review, later use an actual supported development connection in the intended
host, the exact package version and the manifest prompts. Record readable prompts,
tool calls/results, unknown data and boundaries. Keep private material off screen.
Play back the recording and host it at the publisher's chosen accessible location.
Add `review.demo_recording_url` only after verifying the actual video and access.
A script, screenshot, local video or unverified URL does not complete it.
No recording or video hosting was created here.
