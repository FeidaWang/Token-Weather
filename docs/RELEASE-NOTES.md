# Token Weather open-source 1.0.0

Released on 11 October 2026. MIT source, with no publisher-hosted shared budget service. This edition is separate from the earlier pure-skills 1.0.0 candidate and has not been submitted or approved in the plugin directory.

- Add explicit-number `plan_context_budget`, task/output reserves and a five-turn reference outlook.
- Add a calling skill and an actual local MCP browser demonstration.
- Support local stdio and HTTP, defaulting to loopback. Owner-managed reverse-proxy deployment requires an exact HTTPS origin.
- Include optional Docker/Caddy source and a remote-config helper; no deployment is executed.
- Rewrite user guides, self-hosting, privacy, support, terms, listing and review materials for user-controlled deployments.
- Retain the original local Codex runtime, single-page UI, checkpoints and normal hook review. Keep old candidate ZIPs unchanged.

No paid model API, new subscription, purchase, cloud resource, upload or review submission is part of this preparation. Deployer/host charges remain the deployer's responsibility; free hosted operation is not guaranteed.

- Add a separate local-only inspect_local_context MCP and watch command to read compatible metrics and refresh advisory budgets.
- Verify the native Python subprocess behind a real temporary TLS proxy, including certificate/hostname checks and all numeric cases. No public service is deployed.
- Keep model/effort/chat control disabled until exact-owner and runtime-policy verification is available.
