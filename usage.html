Use Token Weather

Open-source version 1.0.0. Source distribution is separate from directory approval.

Local numeric demonstration

Use an existing Python 3.9+ runtime, unpack the release ZIP, then run from its root:

python3 -B mcp/demo/server.py --port 0

Open the printed local URL. The browser calls the real MCP using synthetic numbers. Stop with Ctrl+C. No new subscription or paid model API is needed.

Automatic local Codex observations

The local stdio entry point exposes inspect_local_context in addition to numeric planning. Bind the exact root ID and matching absolute workspace from trusted host metadata. Local parsing needs Python 3.11+. Do not select the latest unrelated chat.

In your current Codex project, with CODEX_THREAD_ID correctly set, refresh local observations:

python3 /path/to/source/scripts/local-observe.py --workspace . --watch --interval 5

Replace the documentation path with your actual source location; provide --thread when no correct host binding is available. Ctrl+C stops it. The reader returns available usage estimates, model/effort, cache information, output average and account windows. It returns no messages, IDs or paths, and updates advisory budgets only. Missing/stale observations cannot drive current advice.

A suggested output reserve is a labelled heuristic based on observed output, not a model output limit or monetary guarantee. Model, effort and automatic chat-switching controls are disabled; see Automation.

Numeric task planning

When your planning MCP is connected, provide a reference of 100000, usage of 65000, a task increase of 20000 and output reserve of 5000. It returns current headroom 35000, planned usage 90000 and planned headroom 10000. Keep the output reserve separate. A five-turn outlook needs three to six compatible chronological totals; the last matches current usage.

The remote tool accepts numeric inputs only and has no private ChatGPT/Codex/account access. Platform/model names do not establish usage or a limit.

Optional original local weather page

With Python 3.11+ and compatible local records, request the local Codex weather or open the original Token Weather page. The page is unchanged. It can keep collecting after closing the tab; stop its service explicitly. Checkpoints use enrolled workflows and automatic chat moving stays off. The separate hooks package keeps normal /hooks review.
