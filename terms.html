Function and limits

Token Weather provides estimates of local Codex chat usage, recent measurements and an advisory outlook. Readings depend on available local records and supported formats. They can be unavailable or stale; an estimate is not a guarantee of remaining capacity, throughput, account quota or avoidance of compaction. The output-per-second figure includes tool waits.

Local execution and compatible Codex records are required for weather readings. ChatGPT on the web cannot read those records. Optional checkpoints store task notes in an already enrolled project workflow. Automatic chat rotation remains disabled. The public package has no lifecycle hooks; the separate local package requires Codex's normal /hooks review.
